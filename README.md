# 🍎 Fruit Freshness Classifier
Ce projet utilise une approche hybride Scala et Python pour classer les fruits comme "frais" ou "pourris". Il combine la puissance de traitement de données de Scala avec la flexibilité du Machine Learning en Python.

### 📌 Objectifs
L'objectif est de fournir une solution complète, de la donnée brute à la visualisation :
- Ingénierie des données (Scala) : collecte, nettoyage et extraction
- Machine Learning (Python) : création et entraînement de modèles pour la classification
- Visualisation (Streamlit) : tableau de bord interactif

### 📊 Dataset
Les images utilisées pour l'entraînement proviennent de Kaggle :
- Fruit Freshness Classification (Fresh vs Rotten) de Muhammad Abdul Rafey Yashir
- Fruits fresh and rotten for classification de Sriram Reddy Kalluri
